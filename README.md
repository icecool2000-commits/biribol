# Biribol Oficial Mococa – Presença nos treinos

App (PWA) de lista de presença, ranking e histórico dos treinos.
Treinos: terça e quinta às 19:00, domingo às 10:00.

- Site: https://icecool2000-commits.github.io/biribol/
- Dados: Firebase Firestore (projeto `biribol-mococa`, plano gratuito Spark)
- Regras de segurança: `firestore.rules` (cópia do que está publicado no console)
- Organizador: contas listadas em `config.js` (ADMIN_EMAILS) e em `firestore.rules`
